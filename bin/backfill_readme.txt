Запустите один раз:

bash
php /var/www/www-root/data/www/roadrunnersteam.ru/pulse/bin/backfill-activity-fingerprints.php
Скрипт пройдёт по всем активностям без fingerprint и проставит значения.

Осторожно: если у вас уже есть дубликаты в базе — скрипт не станет их удалять, просто проставит одинаковые fingerprint разным записям. Это нормально — при следующей загрузке такого же файла отказ сработает.
